# 0001: Project name: Kantahan

Status: Accepted (2026-10-23)

## Context

The brief requires independent branding that does not imply affiliation with Platinum Karaoke or Vismay International Corporation. The name should be easy to say and spell, and fit the Filipino karaoke context the catalog serves.

## Decision

**Kantahan**: Tagalog for a place or occasion for singing (from *kanta*, "song/sing"). Alternatives considered: Hanap Kanta ("find song"), Awitan ("singing session"), Numero Kanta ("song number").

## Consequences

- The name, logo and copy avoid "Platinum", "Reyna" and "Vismay" and any lookalike marks.
- Repository: `thekovie/kantahan`.
